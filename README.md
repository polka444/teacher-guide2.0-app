## 🎯 О проекте

Приложение создано для преподавателей, чтобы помочь организовать учебный процесс. Здесь можно:

- Вести **журнал успеваемости** (ученики, оценки, средний балл, должники)
- Смотреть **программу курса** с разделами и часами
- Изучать **методики обучения** с подробными описаниями
- Хранить **расписание** (поддерживается импорт из Excel)
- Делать **личные заметки** — они сохраняются между запусками
- Ознакомиться с **планируемыми результатами** (цели, задачи, изменения)

---

## 🖥️ Технологии

- **Python 3.7+**
- **Tkinter** — графический интерфейс
- **Openpyxl** — работа с Excel (расписание)
- **JSON** — хранение данных (пользователи, заметки, ученики, оценки)

## 📦 Установка и запуск

### 1. Установите Python

Скачайте с [официального сайта](https://www.python.org/downloads/) (версия 3.7 или выше).  
При установке **обязательно поставьте галочку** `Add Python to PATH`.

### 2. Скачайте приложение

```bash
git clone https://github.com/ВАШ_ЛОГИН/teacher-guide.git
cd teacher-guide
Или просто скачайте ZIP-архив и распакуйте.

3. Установите дополнительные библиотеки
Откройте командную строку (Win+R → cmd) и введите:

bash
pip install openpyxl
Это нужно только для работы расписания из Excel. Если не планируете импортировать расписание, можно пропустить.

4. Запустите приложение
bash
python teacher_app.py
Или просто дважды кликните по файлу teacher_app.py.
